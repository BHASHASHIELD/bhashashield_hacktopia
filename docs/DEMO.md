# Demo walkthrough

1. Open the Live workspace.
2. Choose **Safe family call** and run the analysis. It returns LOW with known-contact evidence.
3. Choose **Government scheme scam**. It returns CRITICAL with scheme context, urgency, and credential-request evidence.
4. Choose **AI voice impersonation** to show that synthetic voice is one input in a larger risk decision.
5. Open **Trusted people** to add a contact. New contacts are visibly unverified until independently confirmed.
6. Open **Verify a number**, search the synthetic directory, and compare a claimed number against the exact stored number.
7. Toggle offline / limited analysis in the workspace to see the lower-confidence status language.

All institutions and numbers in this walkthrough are synthetic demo data. Do not use them as official contact information.
